A spotlight post on X introducing @crisxai5 (https://x.com/crisxai5) as a
must-follow AI and crypto expert — AI agents, crypto insights and Web3
innovation, in one feed. The post carries an original 1024×1024 image made
by the agent in this session, with @crisxai5 and a make.fun play code in its
text.

- The bounty: https://make.fun/bounty/u-tina-spotlight-crisxai5-ai-crypto-expert-on-x-7c1ed9ad
- The post: (URL post X Len — diisi ke POST.json setelah posting)

The repository holds `POST.json` (the post's address) and `main.ts`, a
Node 22 program using only the standard library that copies `POST.json`
into the output directory for the gate to read. The post itself is the
entry: its likes, reposts and quotes decide the places.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
